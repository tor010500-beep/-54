# Инструкция по деплою на GitHub Pages

## Почему возникал белый экран (Blank Page)
1. **GitHub Pages по умолчанию открывал корень репозитория (`/`), а не папку `dist/`**: В корне `index.html` ссылается на TypeScript файл `/src/main.tsx`, который браузер не может запустить напрямую без сборщика Vite.
2. **Абсолютные пути к 3D-модели**: Файлы `/Michelle.glb` и `/michelle_lime.png` запрашивались от корня домена (`username.github.io/Michelle.glb`), а не из подпапки репозитория (`username.github.io/имя_репозитория/`).
3. **Отсутствие файла `.nojekyll`**: GitHub Pages по умолчанию запускает парсер Jekyll, который может блокировать некоторые ассеты.
4. **Отсутствие `404.html`**: При перезагрузке страницы или открытии ссылок GitHub Pages отдавал стандартную ошибку 404.

## Способ 1: Автоматический деплой через GitHub Actions (Рекомендуется)

В проект уже добавлен готовый файл рабочего процесса `.github/workflows/deploy.yml`.

### Шаги настройки:
1. Запушьте код в ваш GitHub репозиторий:
   ```bash
   git add .
   git commit -m "Configure GitHub Pages deployment"
   git push origin main
   ```
2. Откройте ваш репозиторий на GitHub.
3. Перейдите во вкладку **Settings** (Настройки) -> слева в меню выберите **Pages**.
4. В блоке **Build and deployment**:
   - В поле **Source** выберите: **GitHub Actions** (вместо "Deploy from a branch").
5. Перейдите во вкладку **Actions** в репозитории — вы увидите автоматический запуск сборки `Deploy to GitHub Pages`.
6. Через 1–2 минуты ваш сайт откроется по адресу:
   `https://<ваш_логин>.github.io/<имя_репозитория>/` без белого экрана и со всеми 3D-моделями!

## Способ 2: Деплой через терминал командой `npm run deploy`

В `package.json` настроен пакет `gh-pages`:
1. Запустите в терминале:
   ```bash
   npm run deploy
   ```
2. Скрипт автоматически соберет проект (`npm run build`) и загрузит содержимое папки `dist` в ветку `gh-pages`.
3. В **Settings** -> **Pages** выберите ветку `gh-pages` и папку `/ (root)`.
